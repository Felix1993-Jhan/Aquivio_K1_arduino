## 1. 系統概覽

### 1.1 產品定位

K1 由兩部分組成:

- **上位機**(觸控螢幕軟體):介面、配方、水量換算
- **Arduino Mega 2560(本韌體)**:泵、閥、UVC 開關與流量計計數

兩者以 USB 序列埠溝通。

K1 韌體有兩個版本:

| 版本 | 分支 | 協定 | 上位機 |
|---|---|---|---|
| K1 優化版 | `main-v4` | 原 K1 協定(JSON + `#`、9600) | K1 上位機 |
| **K2 移植版(本文件)** | `main-k2port-v4` | K2 UART 協定(`40 71 30` + CS、115200) | 使用 K2 協定的上位機 |

K2 移植版的目的：讓 K1 使用與 K2 相同的命令與裝置 ID,上位機可以沿用。K2 的程式能搬的都搬過來，再改成 K1 的腳位與硬體;K1 沒有的硬體功能，回覆固定的「不支援」格式。

### 1.2 與原 K1 韌體的差異

| 原 K1(公司倉 `main31` / `mcu31v2`) | K2 移植版 |
|---|---|
| JSON 命令 + 文字命令(`#` 結尾)、9600 | K2 二進位封包、115200 |
| 出杯流程阻塞主迴圈 | 1 ms tick,主迴圈不阻塞 |
| `digitalWrite` / `pinMode` | 直接存取暫存器 |
| 流量計 PCINT 中斷、無 debounce | 1 ms 取樣 debounce(同 K2) |
| 韌體以 L 換算水量 | 韌體只計 pulse,換算由上位機做 |
| 主動送 `mcuAlive` / `ready` | 不主動送(只有 `0x06` 完成通知) |

## 2. 系統架構

### 2.1 硬體框圖

```
          上位機
            │ USB
     ┌──────┴──────┐
     │ ATmega16U2  │ USB ↔ UART(DTR → RESET)
     └──────┬──────┘
            │ UART0 115200
┌───────────┴──────────────────────────────────────┐
│                  ATmega2560                      │
│  Timer5 1 ms ── 流量計取樣                         │
│  看門狗 8 s                                       │
└──┬──────────┬───────────┬──────────┬──────────┬──┘
   ↓          ↓           ↓          ↓          ↓
 slot×10    水泵       常溫/冷水閥   UVC×2     流量計 A8
 (ID0~9)   (ID10)     (ID14/15)  (ID12/13)   (ID18)
```

### 2.2 軟體架構

```
Timer5 ISR(1 ms):tick 計數、流量計取樣 ── 只讀不寫輸出
              │
主迴圈 loop():tick_service() → 每 1 ms 一次 tick_main()(計時、扣 pulse、freeflow、關閉到時裝置)
              cmd_poll()     → 收包、處理命令、回覆進 TX 佇列
              tx_poll()      → TX 佇列送出
```

K2 在 1 ms 中斷內做的計時工作,K1 改在主迴圈的 `tick_main()` 補跑(方案 A)。除了流量計數外，所有狀態變數都只在主迴圈存取，不需要關中斷保護。細節見 [docs/modules.md 第 2 節](docs/modules.md#2-執行模型)。

### 2.3 資源使用

| 項目 | 正式版 | 上限 |
|---|---|---|
| Flash | 6298 byte(2%) | 253952 byte(扣除 bootloader) |
| SRAM(全域變數) | 1305 byte(15%) | 8192 byte |

主要 RAM:TX 佇列 512 byte、Serial 收 / 發緩衝各 64 byte、命令收 / 發緩衝各 64 byte。

## 3. 受控裝置與感測器

### 3.1 輸出裝置(裝置 ID 同 K2)

| ID | 裝置 | K1 腳位 |
|---|---|---|
| 0~9 | slot1~10(營養液泵) | D8 / D9 / D10 / D11 / D12 / D3 / D7 / D6 / D5 / D4 |
| 10 | 水泵 | A13 |
| 12 / 13 | UVC1 / UVC2 | A9 / A10(目前實機尚未接 UVC) |
| 14 / 15 | 常溫閥 / 冷水閥 | A14 / A15 |
| 11、16、17、25 | UVC0、氣泡水閥、Clean、Container | 無實體:Status 照翻,無腳位輸出 |

### 3.2 感測器

| ID | 感測器 | K1 |
|---|---|---|
| 18 | 流量計 | A8,1 ms 取樣、高 / 低各 3 ms 確認;`0x03` 回 pulse 數 |
| 19~24 | 壓力、溫度、漏水 | 無;`0x03` 回不支援格式 |

### 3.3 指示

| 腳位 | 用途 |
|---|---|
| D23 | 心跳 0.5 Hz,主迴圈卡住即停 |
| D22 | 除錯版:模擬流量計(水泵開著時約 6 Hz),杜邦線接 A8 |
| D66 | 〔暫時〕跟隨流量計 A8 準位(看 LED) |

完整腳位表見 [docs/hardware.md](docs/hardware.md)。

## 4. 通訊協議速覽

### 4.1 封包

```
[0x40] [0x71] [0x30] [CMD] [Data ...] [CS]      全包加總 & 0xFF = 0
```

- 一般命令 9 byte;`0x07` 為 7 + 3N(N ≤ 19)
- 收包逾時 20 ms;CS 錯誤回 `[4..]` 全 `FF`;不認得的 CMD 不回

### 4.2 命令

| CMD | 名稱 | K1 |
|:---:|---|---|
| `0x00` | SWITCH_SET | ✅ 單一裝置定時開啟 |
| `0x01` / `0x02` | SWITCH_START / STOP | ✅ 遮罩開 / 關;`0x02` 結束 freeflow |
| `0x03` / `0x04` | SENSOR_READ / CLEAR | ✅ 只有 ID18 流量 |
| `0x05` | PING | ✅ `0.0.4.0` |
| `0x06` | SET_PULSE | ✅ 依 pulse 數出水，到量送完成通知 |
| `0x07` | LONG_PRESSURE | ✅ freeflow,UVC 一律開 |
| `0x08` / `0x09` / `0x0A` / `0xB0` | — | ❌ 不支援格式 `[代碼] FF [代碼] FF` |
| `0xB5` | STATUS_QUERY | ⚠ K1 自訂：讀 Status / 實際腳位 |

完整格式與範例見 [docs/protocol.md](docs/protocol.md)。

## 5. 運行模式

### 5.1 一般模式(`freeFlow_Run = 0`)

| 命令 | 行為 |
|---|---|
| `0x00` | 開啟單一裝置,24-bit 毫秒倒數到 0 關閉(0 = 不自動關) |
| `0x01` / `0x02` | 遮罩開 / 關，不限時 |
| `0x06` | 開水泵 + 常溫 / 冷水閥，每個流量 pulse 扣 1,扣到 0 關閉並送完成通知 |

### 5.2 freeflow 常溫 / 冷水模式(`freeFlow_Run = 1`)

由 `0x07` Type 0 / 1 進入,`0x02` 結束。

```
開啟:水泵 + 常溫 / 冷水閥 + UVC ID11~13
每個流量 pulse(上位機給的時間值 = 每 pulse 開幾 ms,上限 150):
    acc += 時間值                      (上限 250)
acc ≥ 100 → 開 slot 100 ms → acc −= 100 → 剩 < 100 才關
```

- slot 開啟時間與流量成正比，水流快 slot 開得多，配比維持固定
- 收到 0x07 時，各 slot 的 acc 起點依 ID 順序輪流設為 17 / 50 / 83
  - 同比例的 slot 不會同時開，出水口不會一下子多出好幾個 slot 的料
- `N = 0`:停料、只出水(沖洗)
- freeflow 中 `0x00` 倒數暫停

氣泡水模式(K2 的 `freeFlow_Run = 2`)K1 沒有。

## 8. 開發注意事項

### 8.1 程式規範

- 修改判斷邏輯時，舊程式以註解保留，並在註解開頭寫明原因(換掉什麼、換成什麼)
- 與 K2 不同的地方，在程式註解標 `K1` 並說明
- 模組放 `mcu/` 根目錄(Arduino IDE 只編譯 sketch 根目錄的檔案)
- 共用模組(`pins`、`tick`、`flowmeter`、`pressure`、`diagnostics`、`tx_queue`)在 `main-v4` 修正後合併過來，不反向合併

### 8.2 AVR 相關

- `int` 只有 16-bit:位元遮罩用 `DEV_BIT(id) = 1UL << id`;組 32-bit 值先轉 `uint32_t` 再移位
- 讀寫 16 / 32-bit 的 ISR 共用變數要 `ATOMIC_BLOCK`
- Port H / J / K / L 的讀改寫不是原子操作 → 輸出腳只在主迴圈寫
- Arduino `init()` 會設定 Timer5 與 ADC,自己用時要整個暫存器重寫

### 8.3 硬體相關

- 開 port 即重開機(16U2 DTR → RESET),上位機開 port 後約 2 秒才能送命令
- 燒錄前關掉上位機
- 空板測試用除錯版 + D22 → A8 杜邦線;上機用正式版
