# 功能狀態與版本紀錄(K1 K2 移植版)

> 分支 `main-k2port-v4`。上半部是**目前功能狀態**,下半部是版本歷程。〔[沿革](#沿革)〕

## 目前功能狀態(0.0.4.0)

### 〔暫時〕存在但之後要決定去留

| 項目 | 說明 | 停用方式 |
|---|---|---|
| D66 與流量計 A8 同步 | 看板上 LED 判斷流量計訊號;轉接板上 D66 沒接負載 | `tick_main()` 裡的 `diag_flow_mirror_1ms()` 註解掉 |
| `0xB5` 狀態查詢 | K1 自訂測試命令;正式版是否保留〔待定〕 | — |

### 只在除錯版

| 項目 | 說明 |
|---|---|
| D22 模擬流量計 | 水泵開著時約 6 Hz,固定頻率;以杜邦線接 A8 |

### 存在但未對外

| 項目 | 說明 |
|---|---|
| A1 水壓 ADC | 每 200 ms 取樣，程式保留;K2 協定的 `0x03` ID20 回不支援格式 |
| `FLOW_UL_PER_PULSE` | 共用模組的常數(3.3 ml / pulse),本分支不換算 ml,沒有用到 |

### 不支援(K1 沒有硬體)

`0x08`、`0x09`、`0x0A`、`0xB0`、`0x03` 流量以外的 ID、Type 2 氣泡水。詳見 [k2_diff.md](k2_diff.md)。

### 已知限制(同 K2,不修正)

- `0x06` 被 `0x02` 中斷時剩餘 pulse 不清除
- 連續兩包 `0x07` 中間沒有 `0x02` 時不清除前一包的狀態

詳見 [k2_diff.md 第 6 節](k2_diff.md#6-兩邊相同的已知限制照-k2不修正)。

### 驗證狀態

- 空板(除錯版 + D22 模擬流量計):`tools/portK2_tool/` 五支腳本全部通過
- **尚未上機驗證**:實際流量計頻率、出水口效果、K2 上位機實際連線

# 版本歷程

## 0.0.4.0 — K2 移植版(2026-11-11 ~ 11-12,進行中)

以 K1 優化版(`main-v4` `d62eadb`)為基底，通訊改用 K2 UART 協定。

| commit | 日期 | 內容 |
|---|---|---|
| `d6a2d44` | 11-11 | (由 `main-v4` 合併)腳位修正:watervalve / bevvalve 改為轉接板實際接線 A11 / A12,新增 carbonated A9、spout A10 |
| `3f8c624` | 11-11 | **P1** 改用 K2 收包(`40 71 30` + CS、115200、20 ms 逾時、標頭逐 byte 比對),移除 JSON / 文字命令與主動輸出 |
| `f581619` | 11-11 | **P2** 裝置 ID 對照與 `0x00` / `0x01` / `0x02`;K1 自訂 `0xB5` 狀態查詢 |
| `29c2f82` | 11-11 | **P3** `0x03` / `0x04` 流量讀取與歸零、長度查表、不支援功能回覆格式(`0x08` / `0x09` / `0x0A` / `0xB0`) |
| `da70079` | 11-11 | **P4** `0x06` SET_PULSE 依流量脈衝數出水與完成通知(修正 K2 完成通知的 CS 位置) |
| `0551a28` | 11-11 | **P5** `0x07` freeflow 常溫 / 冷水;開 slot 條件改 `≥ 100`;N 上限 19;`0x02` 重置 freeflow;〔暫時〕D66 同步流量計 |
| `a19a9b3` | 11-12 | freeflow slot 的 acc 起點錯開 17 / 50 / 83 |
| `b74d5a3` | 11-12 | `0x07` 一律開 UVC ID11~13 |
